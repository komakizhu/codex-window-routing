# 两种选屏方式验收

版本：0.1.0。检查日期：2026-10-30。本记录针对本次新增的选屏设置；完整结果见[检查数据](placement-mode-results.json)。

## 结果与用法

功能已经同步到实际运行的 Hammerspoon，菜单栏入口为 `CU副屏 ●`。

- **跟随焦点，使用另一块屏**：当前焦点窗口在哪块屏，另一块就是副屏；鼠标只是移动不改变选屏。
- **固定使用指定副屏 → 屏幕名称**：选定后使用该屏幕 UUID，焦点改变不影响目标；目标断开时暂停移动，重新认到同一 UUID 后恢复。
- 勾号显示当前方式，菜单中的“目标副屏”显示当前目标名称。选择会自动保存。

测试结束已恢复任务开始时的设置：**跟随焦点，自动分配开启**。本次没有替用户保留一个固定副屏选择。

## 模拟规则检查

[检查脚本](placement_modes.lua)加载本次真实 Lua 模块，提供模拟的 Hammerspoon 屏幕、窗口、定时器、菜单和偏好设置；不操作真实窗口。**9 项检查全部通过**：

1. 默认方式跟随焦点；移动鼠标不改变目标；没有可用焦点时停手。
2. 固定方式不依赖焦点，也能在多于两块屏幕时找到指定屏幕；跟随方式仍要求两块。
3. 菜单选择正确保存；模拟重新启动后能恢复选择；切回跟随方式也会记住。
4. 指定屏幕断开时不改选其他屏幕；同一 UUID 换编号重新连接后恢复。
5. 模式切换只移动 Codex 已识别的小预览和控制窗；普通 Codex、Safari、Obsidian 窗口不动；已经到位的不重复移动；移动不调用激活或聚焦接口。

7. 同名屏幕有不同菜单入口，仍按 UUID 选择，不受顺序和编号变化影响。
8. 偏好设置无效时安全处理；固定方式缺少目标时不猜目标。
9. 移动事件仍在等待时切换模式，会使用新的选择，不使用旧目标。
