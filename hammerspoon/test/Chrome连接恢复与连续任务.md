## 已部署的工作区管理

- 新增 `ensureChromeWorkspace`：使用 Chrome 原生窗口及标签组接口，创建或复用有明确编号的工作窗。工作窗使用绿色标签组“Codex 副屏工作窗”标识。它是本项目交付的长期窗口安排，任务页面另外打开，不保留临时测试页。
- 新增 Hammerspoon `rememberChromeWorkspace`：保存 Chrome 进程、连接、窗口、标签和组编号。进程变化后不使用旧记录；不同连接不误用记录。窗口混入其他标签、或工作窗已被用来浏览其他网页时停止，避免移动个人窗口。
- 最终保留窗口 `2137711402`、标签 `2137711403`、标签组 `1830420957`。新建后仍为副屏后台；实际重载 Lua 后记录保留，重新调用返回 `reused:true`，没有重复创建。
- 临时检查窗口 `993` 已清理。最终工作窗留在副屏，标签组名称可见；[最终窗口与配置检查](chrome-workspace-final.json)记录了实际位置和状态。
- 一个自定义 `data:` 状态页尝试被浏览器 URL 安全策略拦截，已放弃并清理其临时窗口。最终方案只使用原生标签组标识，没有创建自定义页面或绕过 URL 拦截。

调用说明见 [项目规则](../../AGENTS.md) 和 [使用说明](../README.md)，实现见 [浏览器函数](../../browser/chrome_work_window.mjs) 与 [Lua 模块](../computer_use_sidecar.lua)。没有改动全局 Agent 规则或 Codex 内置工具。
